## 📁 Структура файлов проекта

| Файл | Тип | Описание |
| :--- | :--- | :--- |
| **`Сборка.a3d`** | Сборка | Главная сборка корпуса со всеми деталями |
| `Верхняя часть корпуса.m3d` | Деталь | Верхняя крышка корпуса |

| `Передняя, стенка.m3d` | Деталь | Передняя панель |
| `Задняя деталь.m3d` | Деталь | Задняя панель с технологическими отверстиями |
| `Боковая деталь.m3d` | Деталь | Боковая стенка (левая) |
| `Боковая стенка 2.m3d` | Деталь | Боковая стенка (правая) |
| `Держатель для радиатора светодиода.m3d` | Деталь | Внутреннее крепление радиатора охлаждения LED |

## ⚙️ Требования и совместимость

- **САПР:** КОМПАС-3D (рекомендуется указать вашу версию, например *v21 / v22 / v23*)
- **Обратная совместимость:** Обратите внимание, что КОМПАС-3D обычно не открывает файлы, созданные в более новых версиях программы, в более старых без предварительного экспорта в обменные форматы.

---

## 💡 Рекомендации для работы с проектом на GitHub

1. **Экспорт в STL для интерактивного 3D на GitHub:**
   - GitHub умеет отображать 3D-файлы **`.stl`** прямо в браузере с возможностью вращения мышкой.
   - Рекомендуется экспортировать детали или сборку в формат `.stl` и загрузить в репозиторий (например, в папку `stl/`) для быстрого предпросмотра и 3D-печати.
2. **Экспорт в STEP для совместимости:**
   - Файлы **`.step`** (`.stp`) позволят другим пользователям открывать модели в любых других САПР (FreeCAD, SolidWorks, Fusion 360, Blender и т.д.).
3. **Резервные копии (`*.bak`):**
   - Файлы `.bak`, создаваемые КОМПАС-3D при сохранении, исключены из отслеживания через `.gitignore`.
