# Projector — Корпус проектора в КОМПАС-3D

3D-модель корпуса проектора и крепления радиатора светодиода, разработанная в САПР **КОМПАС-3D**.

## 📁 Структура файлов проекта

Все детали и сборка упорядочены по узлам и функциональному назначению:

| Файл | Тип | Описание |
| :--- | :--- | :--- |
| **`00_Сборка_корпуса.a3d`** | Сборка | Главная 3D-сборка корпуса со всеми деталями и крепежом |
| `01_Передняя_панель.m3d` | Деталь | Лицевая панель корпуса с замковыми пазами |
| `02_Задняя_панель.m3d` | Деталь | Задняя панель с вырезами под два 120-мм вентилятора охлаждения |
| `03_Нижняя_панель.m3d` | Деталь | Нижнее основание корпуса (дно) |
| `04_Верхняя_крышка.m3d` | Деталь | Верхняя защитная панель-крышка |
| `05_Боковая_панель_левая.m3d` | Деталь | Левая глухая боковая стенка |
| `06_Боковая_панель_правая.m3d` | Деталь | Правая стенка с вырезами под разъём питания IEC C14 и порт HDMI |
| `07_Держатель_радиатора_светодиода.m3d` | Деталь | Кронштейн (воздуховод) крепления радиатора LED на задней стенке |
| `08_Уголок_крепежный.m3d` | Деталь | Угловой компактный кронштейн для стяжки стенок (8 шт. в сборке) |
| `09_Держатель_отражателя.m3d` | Деталь | Рамка-держатель отражателя светодиода |

### Вспомогательные файлы и экспорт:
- `02_Чертеж_задней_панели.dxf` — развертка/чертеж задней стенки для резки.
- `06_Боковая_панель_правая.stl` — STL для 3D-печати правой стенки.
- `07_Держатель_радиатора_светодиода.stl` — STL для 3D-печати кронштейна радиатора LED.
- `08_Уголок_крепежный.stl` — STL для 3D-печати угловых кронштейнов.
- `09_Держатель_отражателя.stl` — STL для 3D-печати держателя отражателя.
- `backups/` — архив всех резервных копий (`*.bak`) и промежуточных итераций.

## ⚙️ Требования и совместимость

- **САПР:** КОМПАС-3D v25
- **Обратная совместимость:** Обратите внимание, что КОМПАС-3D обычно не открывает файлы, созданные в более новых версиях программы, в более старых без предварительного экспорта в обменные форматы.
